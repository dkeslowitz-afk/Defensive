# Defensive

A mobile-first tower defense game. Plain HTML/CSS/JS + canvas, no build step.

- **Play:** open `index.html` (or the GitHub Pages URL once Pages is enabled on `main`).
- **Balance numbers:** all in `js/config.js`.
- **Balance check (optional):** `node tools/sim.js` lets bots play runs headlessly and prints which wave they reach.
- **Project rules and code map:** see `CLAUDE.md`.
